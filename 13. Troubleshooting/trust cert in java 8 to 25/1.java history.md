# Java History

Java has moved to a six-month release cadence following Java 8, resulting in numerous versions categorized into Long-Term Support (LTS) versions and Short-Term Feature versions.

---

## 🗓️ Major Java Releases (Post-Java 8)

| Version      | Release Date | Release Type | Key Milestone Features                                              |
| ------------ | ------------ | ------------ | ------------------------------------------------------------------- |
| Java 8       | March 2014   | LTS          | Lambda Expressions, Stream API, New Date/Time API                   |
| Java 9       | Sep 2017     | Feature      | Project Jigsaw (Module System), jshell REPL                         |
| Java 10      | Mar 2018     | Feature      | Local Variable Type Inference (var)                                 |
| Java 11      | Sep 2018     | LTS          | New HTTP Client, Flight Recorder, Launch Single-File Source Code    |
| Java 12 & 13 | 2019         | Feature      | Switch Expressions (Preview), Text Blocks (Preview)                 |
| Java 14 & 15 | 2020         | Feature      | Pattern Matching for instanceof (Preview), Sealed Classes (Preview) |
| Java 16      | Mar 2021     | Feature      | Records (Final), Pattern Matching for instanceof (Final)            |
| Java 17      | Sep 2021     | LTS          | Sealed Classes (Final), Strongly Encapsulate JDK Internals          |
| Java 18 & 19 | 2022         | Feature      | Simple Web Server, Virtual Threads (Preview)                        |
| Java 21      | Sep 2023     | LTS          | Virtual Threads (Final), Sequenced Collections, Record Patterns     |
| Java 22 & 23 | 2024         | Feature      | Stream Gatherers (Preview), Markdown Documentation Comments         |
| Java 25      | Sep 2025     | LTS          | Flexible Constructor Bodies, Derived Record Creation                |
| Java 26      | Sep 2026     | Feature      | Current Release                                                     |

---

> Java 8 was released in March 2014 and represents one of the most significant architectural shifts in Java history. It introduced functional programming concepts that completely changed how Java code is written.
