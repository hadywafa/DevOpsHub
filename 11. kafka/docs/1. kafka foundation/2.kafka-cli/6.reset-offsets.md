# Kafka CLI — Reset Consumer Group Offsets

Resetting offsets means:

> Change where a consumer group will continue reading.

It **does not delete or modify Kafka messages**.

## Kafka Reset Offsets Types

![[Pasted image 20260726180715.png]]

1. Replay all available messages
    - Move the group back to the earliest available offsets.
2. Skip all existing messages
    - Move the group to the end of every partition.
3. Replay the previous three records
    - Move each partition three offsets backwards.
4. Start from a specific offset
    - Move every selected partition to offset `5`.

## Important

```text
1. Stop all consumers in the group
2. Check current offsets
3. Preview the reset
4. Execute the reset
5. Restart consumers
```

Kafka requires the consumer group to be inactive before resetting its offsets. Without `--execute`, the command only previews the result. ([Apache Kafka](https://kafka.apache.org/43/operations/basic-kafka-operations/?utm_source=chatgpt.com 'Basic Kafka Operations | Apache Kafka'))

## Labs

We will use:

```text
Group: orders-service
Topic: orders
```

Check current offsets

```bash
docker compose exec kafka-1 \
  /opt/kafka/bin/kafka-consumer-groups.sh \
  --bootstrap-server kafka-1:19092 \
  --group orders-service \
  --describe
```

Example:

```text
TOPIC  PARTITION  CURRENT-OFFSET  LOG-END-OFFSET  LAG
orders 0          10              15              5
```

This means:

```text
Next record to consume = offset 10
Records remaining      = 5
```

## 1. Replay all available messages

Move the group back to the earliest available offsets.

### Preview

```bash
docker compose exec kafka-1 \
  /opt/kafka/bin/kafka-consumer-groups.sh \
  --bootstrap-server kafka-1:19092 \
  --group orders-service \
  --topic orders \
  --reset-offsets \
  --to-earliest
```

### Execute

```bash
docker compose exec kafka-1 \
  /opt/kafka/bin/kafka-consumer-groups.sh \
  --bootstrap-server kafka-1:19092 \
  --group orders-service \
  --topic orders \
  --reset-offsets \
  --to-earliest \
  --execute
```

Use when:

```text
You fixed a bug and want to reprocess all retained records.
```

## 2. Skip all existing messages

Move the group to the end of every partition.

### Preview

```bash
docker compose exec kafka-1 \
  /opt/kafka/bin/kafka-consumer-groups.sh \
  --bootstrap-server kafka-1:19092 \
  --group orders-service \
  --topic orders \
  --reset-offsets \
  --to-latest
```

### Execute

```bash
docker compose exec kafka-1 \
  /opt/kafka/bin/kafka-consumer-groups.sh \
  --bootstrap-server kafka-1:19092 \
  --group orders-service \
  --topic orders \
  --reset-offsets \
  --to-latest \
  --execute
```

Use when:

```text
You want the group to ignore old records and consume only new ones.
```

Be careful: existing unprocessed records will be skipped.

---

## 3. Replay the previous three records

Move each partition three offsets backwards.

### Preview

```bash
docker compose exec kafka-1 \
  /opt/kafka/bin/kafka-consumer-groups.sh \
  --bootstrap-server kafka-1:19092 \
  --group orders-service \
  --topic orders \
  --reset-offsets \
  --shift-by -3
```

### Execute

```bash
docker compose exec kafka-1 \
  /opt/kafka/bin/kafka-consumer-groups.sh \
  --bootstrap-server kafka-1:19092 \
  --group orders-service \
  --topic orders \
  --reset-offsets \
  --shift-by -3 \
  --execute
```

Example:

```text
Before: CURRENT-OFFSET = 10
After:  CURRENT-OFFSET = 7
```

Important:

```text
-3 = move backwards and replay
+3 = move forwards and skip
```

The shift applies separately to every selected partition. Kafka adjusts an out-of-range result to the available beginning or end. ([Apache Kafka](https://kafka.apache.org/43/operations/basic-kafka-operations/?utm_source=chatgpt.com 'Basic Kafka Operations | Apache Kafka'))

## 4. Start from a specific offset

Move every selected partition to offset `5`.

### Preview

```bash
docker compose exec kafka-1 \
  /opt/kafka/bin/kafka-consumer-groups.sh \
  --bootstrap-server kafka-1:19092 \
  --group orders-service \
  --topic orders \
  --reset-offsets \
  --to-offset 5
```

### Execute

```bash
docker compose exec kafka-1 \
  /opt/kafka/bin/kafka-consumer-groups.sh \
  --bootstrap-server kafka-1:19092 \
  --group orders-service \
  --topic orders \
  --reset-offsets \
  --to-offset 5 \
  --execute
```

This means the next consumed record will be offset `5`.

Remember:

```text
Partition 0, offset 5
is different from
Partition 1, offset 5
```

## Verify after any reset

```bash
docker compose exec kafka-1 \
  /opt/kafka/bin/kafka-consumer-groups.sh \
  --bootstrap-server kafka-1:19092 \
  --group orders-service \
  --describe
```

Then restart the consumer normally:

```bash
docker compose exec kafka-1 \
  /opt/kafka/bin/kafka-console-consumer.sh \
  --bootstrap-server kafka-1:19092 \
  --topic orders \
  --group orders-service
```

You do not need `--from-beginning`; the group now resumes from the newly committed offsets.

## Commands to memorise

```text
--to-earliest
→ Replay everything available

--to-latest
→ Skip existing messages

--shift-by -3
→ Replay three offsets per partition

--to-offset 5
→ Continue from offset 5

No --execute
→ Preview only

--execute
→ Apply the reset
```
