# Kafka Java Consumer — Rebalance Demo

This single class can run in two modes:

```text
eager       → RangeAssignor
cooperative → CooperativeStickyAssignor
```

It logs:

```text
Assigned partitions
Revoked partitions
Lost partitions
```

Kafka calls `ConsumerRebalanceListener` whenever group membership or topic partition assignments change. In eager mode, all owned partitions are revoked; in cooperative mode, only partitions that must move are revoked. ([Apache Kafka](https://kafka.apache.org/43/javadoc/org/apache/kafka/clients/consumer/CooperativeStickyAssignor.html?utm_source=chatgpt.com 'CooperativeStickyAssignor (kafka 4.3.1 API)'))

---

## 1. Create the class

Create:

```text
src/main/java/com/hady/kafka/KafkaConsumerRebalanceDemo.java
```

```java
package com.hady.kafka;

import org.apache.kafka.clients.consumer.ConsumerConfig;
import org.apache.kafka.clients.consumer.ConsumerRebalanceListener;
import org.apache.kafka.clients.consumer.ConsumerRecord;
import org.apache.kafka.clients.consumer.ConsumerRecords;
import org.apache.kafka.clients.consumer.CooperativeStickyAssignor;
import org.apache.kafka.clients.consumer.KafkaConsumer;
import org.apache.kafka.clients.consumer.RangeAssignor;
import org.apache.kafka.common.TopicPartition;
import org.apache.kafka.common.errors.WakeupException;
import org.apache.kafka.common.serialization.StringDeserializer;

import java.time.Duration;
import java.util.Collection;
import java.util.List;
import java.util.Properties;
import java.util.concurrent.atomic.AtomicBoolean;

public class KafkaConsumerRebalanceDemo {

    private static final String BOOTSTRAP_SERVERS =
            "localhost:29092,localhost:39092,localhost:49092";

    private static final String TOPIC = "orders";

    public static void main(String[] args) {

        String clientId = args.length > 0
                ? args[0]
                : "consumer-1";

        String mode = args.length > 1
                ? args[1].toLowerCase()
                : "cooperative";

        boolean staticMembership =
                args.length > 2
                && args[2].equalsIgnoreCase("static");

        String groupId =
                "orders-" + mode
                + (staticMembership ? "-static-group" : "-group");

        Properties properties = createProperties(
                clientId,
                groupId,
                mode,
                staticMembership
        );

        KafkaConsumer<String, String> consumer =
                new KafkaConsumer<>(properties);

        AtomicBoolean shuttingDown = new AtomicBoolean(false);

        Runtime.getRuntime().addShutdownHook(
                new Thread(() -> {
                    shuttingDown.set(true);
                    consumer.wakeup();
                })
        );

        ConsumerRebalanceListener rebalanceListener =
                new ConsumerRebalanceListener() {

                    @Override
                    public void onPartitionsRevoked(
                            Collection<TopicPartition> partitions
                    ) {
                        System.out.printf(
                                "[%s] REVOKED: %s%n",
                                clientId,
                                partitions
                        );
                    }

                    @Override
                    public void onPartitionsAssigned(
                            Collection<TopicPartition> partitions
                    ) {
                        System.out.printf(
                                "[%s] ASSIGNED: %s%n",
                                clientId,
                                partitions
                        );
                    }

                    @Override
                    public void onPartitionsLost(
                            Collection<TopicPartition> partitions
                    ) {
                        System.out.printf(
                                "[%s] LOST: %s%n",
                                clientId,
                                partitions
                        );
                    }
                };

        try {

            consumer.subscribe(
                    List.of(TOPIC),
                    rebalanceListener
            );

            System.out.printf(
                    "%nClient:     %s%n"
                    + "Group:      %s%n"
                    + "Mode:       %s%n"
                    + "Membership: %s%n%n",
                    clientId,
                    groupId,
                    mode,
                    staticMembership ? "static" : "dynamic"
            );

            while (true) {

                ConsumerRecords<String, String> records =
                        consumer.poll(Duration.ofSeconds(1));

                for (ConsumerRecord<String, String> record : records) {

                    System.out.printf(
                            "[%s] partition=%d, offset=%d, value=%s%n",
                            clientId,
                            record.partition(),
                            record.offset(),
                            record.value()
                    );
                }
            }

        } catch (WakeupException exception) {

            if (!shuttingDown.get()) {
                throw exception;
            }

        } finally {

            System.out.println(clientId + " closing...");
            consumer.close();
        }
    }

    private static Properties createProperties(
            String clientId,
            String groupId,
            String mode,
            boolean staticMembership
    ) {

        Properties properties = new Properties();

        properties.setProperty(
                ConsumerConfig.BOOTSTRAP_SERVERS_CONFIG,
                BOOTSTRAP_SERVERS
        );

        properties.setProperty(
                ConsumerConfig.KEY_DESERIALIZER_CLASS_CONFIG,
                StringDeserializer.class.getName()
        );

        properties.setProperty(
                ConsumerConfig.VALUE_DESERIALIZER_CLASS_CONFIG,
                StringDeserializer.class.getName()
        );

        properties.setProperty(
                ConsumerConfig.GROUP_ID_CONFIG,
                groupId
        );

        properties.setProperty(
                ConsumerConfig.CLIENT_ID_CONFIG,
                clientId
        );

        properties.setProperty(
                ConsumerConfig.AUTO_OFFSET_RESET_CONFIG,
                "earliest"
        );

        switch (mode) {

            case "eager" ->
                    properties.setProperty(
                            ConsumerConfig
                                    .PARTITION_ASSIGNMENT_STRATEGY_CONFIG,
                            RangeAssignor.class.getName()
                    );

            case "cooperative" ->
                    properties.setProperty(
                            ConsumerConfig
                                    .PARTITION_ASSIGNMENT_STRATEGY_CONFIG,
                            CooperativeStickyAssignor.class.getName()
                    );

            default ->
                    throw new IllegalArgumentException(
                            "Mode must be eager or cooperative"
                    );
        }

        if (staticMembership) {

            properties.setProperty(
                    ConsumerConfig.GROUP_INSTANCE_ID_CONFIG,
                    clientId
            );

            properties.setProperty(
                    ConsumerConfig.SESSION_TIMEOUT_MS_CONFIG,
                    "30000"
            );
        }

        return properties;
    }
}
```

# 2. Prepare the topic

Use three partitions:

```bash
docker compose exec kafka-1 \
  /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server kafka-1:19092 \
  --create \
  --if-not-exists \
  --topic orders \
  --partitions 3 \
  --replication-factor 1
```

# 3. Demo eager rebalance

## Terminal 1

```bash
mvn compile exec:java \
  -Dexec.mainClass=com.hady.kafka.KafkaConsumerRebalanceDemo \
  -Dexec.args="consumer-1 eager"
```

Initial result:

```text
[consumer-1] ASSIGNED: [orders-0, orders-1, orders-2]
```

## Terminal 2

```bash
mvn compile exec:java \
  -Dexec.mainClass=com.hady.kafka.KafkaConsumerRebalanceDemo \
  -Dexec.args="consumer-2 eager"
```

Watch terminal 1. A typical eager rebalance looks like:

```text
[consumer-1] REVOKED: [orders-0, orders-1, orders-2]
[consumer-1] ASSIGNED: [orders-0, orders-1]
```

Terminal 2:

```text
[consumer-2] ASSIGNED: [orders-2]
```

### Behaviour

```text
Consumer 1 originally owned 0, 1, 2

Consumer 2 joins

Consumer 1 revokes ALL partitions
Kafka calculates a new assignment
Consumer 1 receives 0, 1
Consumer 2 receives 2
```

This is the stop-the-world eager behaviour.

# 4. Demo cooperative rebalance

Stop the eager consumers, then start the cooperative group.

## Terminal 1

```bash
mvn compile exec:java \
  -Dexec.mainClass=com.hady.kafka.KafkaConsumerRebalanceDemo \
  -Dexec.args="consumer-1 cooperative"
```

Initial assignment:

```text
[consumer-1] ASSIGNED: [orders-0, orders-1, orders-2]
```

## Terminal 2

```bash
mvn compile exec:java \
  -Dexec.mainClass=com.hady.kafka.KafkaConsumerRebalanceDemo \
  -Dexec.args="consumer-2 cooperative"
```

Typical output in terminal 1:

```text
[consumer-1] REVOKED: [orders-2]
[consumer-1] ASSIGNED: [orders-0, orders-1]
```

Terminal 2:

```text
[consumer-2] ASSIGNED: [orders-2]
```

### Behaviour

```text
Consumer 1 keeps partitions 0 and 1
Consumer 1 revokes only partition 2
Consumer 2 receives partition 2
```

`CooperativeStickyAssignor` preserves existing assignments where possible and supports incremental cooperative rebalancing. Every consumer in the group must use the cooperative assignor. ([Apache Kafka](https://kafka.apache.org/43/javadoc/org/apache/kafka/clients/consumer/CooperativeStickyAssignor.html?utm_source=chatgpt.com 'CooperativeStickyAssignor (kafka 4.3.1 API)'))

# 6. Inspect the group assignment

For cooperative mode:

```bash
docker compose exec kafka-1 \
  /opt/kafka/bin/kafka-consumer-groups.sh \
  --bootstrap-server kafka-1:19092 \
  --describe \
  --group orders-cooperative-group \
  --members \
  --verbose
```

Possible output:

```text
CLIENT-ID   #PARTITIONS   ASSIGNMENT
consumer-1  2             orders(0,1)
consumer-2  1             orders(2)
```

Kafka’s consumer-group CLI can display the members and exact partition assignments. ([Apache Kafka](https://kafka.apache.org/43/operations/basic-kafka-operations/?utm_source=chatgpt.com 'Basic Kafka Operations | Apache Kafka'))

# 7. Optional static-membership mode

Start consumers with the third argument:

```bash
mvn compile exec:java \
  -Dexec.mainClass=com.hady.kafka.KafkaConsumerRebalanceDemo \
  -Dexec.args="consumer-1 cooperative static"
```

Second instance:

```bash
mvn compile exec:java \
  -Dexec.mainClass=com.hady.kafka.KafkaConsumerRebalanceDemo \
  -Dexec.args="consumer-2 cooperative static"
```

This sets:

```text
consumer-1 → group.instance.id=consumer-1
consumer-2 → group.instance.id=consumer-2
```

Each simultaneously running consumer must have a unique static ID.

For a realistic static-membership test, the consumer must disappear unexpectedly and restart with the same ID before `session.timeout.ms`. A graceful `Ctrl+C` calls `consumer.close()`, so the consumer intentionally leaves the group.

# What to observe

```text
Eager:

REVOKED: [all currently owned partitions]
ASSIGNED: [new partitions]
```

```text
Cooperative:

REVOKED: [only partitions that must move]
ASSIGNED: [partitions retained or newly assigned]
```

## Memory rule

```text
RangeAssignor
→ Eager rebalance
→ Revoke everything

CooperativeStickyAssignor
→ Incremental rebalance
→ Revoke only what must move

ConsumerRebalanceListener
→ Shows revoked, assigned and lost partitions
```
