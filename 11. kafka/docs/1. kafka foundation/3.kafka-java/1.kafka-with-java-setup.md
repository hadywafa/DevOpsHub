# Kafka with Java — Project Setup

We will create the same small Kafka application twice:

```text
Option 1: Maven  → pom.xml
Option 2: Gradle → build.gradle
```

You normally choose **one build tool**, not both. The Java Kafka code is identical.

For your learning path, I recommend **Maven first** because it is more common in traditional enterprise Java and easier to read. Gradle is useful to understand because many modern projects use it.

## Versions we will use

```text
Java:         21 LTS
Kafka client: 4.3.1
SLF4J:        1.7.36
```

Kafka 4.3 fully supports Java 17, 21 and 25. Java 21 is a good balance between modern Java and broad tooling support. The official Kafka documentation currently specifies `kafka-clients:4.3.1`. ([Apache Kafka](https://kafka.apache.org/43/operations/java-version/?utm_source=chatgpt.com 'Java Version | Apache Kafka'))

The Conduktor guides have the correct project concept, but their examples still show the old Kafka client `2.8.1` and SLF4J `1.7.32`; we will use current dependencies instead. ([Conduktor](https://www.conduktor.io/kafka/creating-a-kafka-java-project-using-maven-pom-xml 'Kafka Maven Project Setup (pom.xml) | Conduktor'))

## 2. Shared Java code

Both Maven and Gradle will use this class:

```text
src/main/java/com/hady/kafka/KafkaConnectionCheck.java
```

It uses Kafka’s `AdminClient` to verify that Java can connect to the cluster.

```java
package com.hady.kafka;

import org.apache.kafka.clients.admin.AdminClient;
import org.apache.kafka.clients.admin.AdminClientConfig;
import org.apache.kafka.common.Node;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.util.Collection;
import java.util.Properties;

public class KafkaConnectionCheck {

    private static final Logger log =
            LoggerFactory.getLogger(KafkaConnectionCheck.class);

    private static final String DEFAULT_BOOTSTRAP_SERVERS =
            "localhost:29092,localhost:39092,localhost:49092";

    public static void main(String[] args) throws Exception {

        String bootstrapServers = System.getenv()
                .getOrDefault(
                        "KAFKA_BOOTSTRAP_SERVERS",
                        DEFAULT_BOOTSTRAP_SERVERS
                );

        Properties properties = new Properties();

        properties.put(
                AdminClientConfig.BOOTSTRAP_SERVERS_CONFIG,
                bootstrapServers
        );

        properties.put(
                AdminClientConfig.CLIENT_ID_CONFIG,
                "kafka-java-connection-check"
        );

        log.info("Connecting to Kafka: {}", bootstrapServers);

        try (AdminClient adminClient = AdminClient.create(properties)) {

            String clusterId = adminClient
                    .describeCluster()
                    .clusterId()
                    .get();

            Collection<Node> nodes = adminClient
                    .describeCluster()
                    .nodes()
                    .get();

            log.info("Connected successfully");
            log.info("Cluster ID: {}", clusterId);
            log.info("Broker count: {}", nodes.size());

            for (Node node : nodes) {
                log.info(
                        "Broker ID: {}, host: {}, port: {}",
                        node.id(),
                        node.host(),
                        node.port()
                );
            }
        }
    }
}
```

Expected result:

```text
Connected successfully
Cluster ID: ...
Broker count: 3
Broker ID: 1, host: localhost, port: 29092
Broker ID: 2, host: localhost, port: 39092
Broker ID: 3, host: localhost, port: 49092
```

This confirms:

```text
Java is working
Dependencies are loaded
Kafka networking is correct
Advertised listeners are correct
The client discovered all brokers
```

## Option A — Maven Setup

```text
    └── main/

```

```bash
nano src/main/java/com/hady/kafka/KafkaConnectionCheck.java
```

Paste the shared Java code above.

---

### 2. Maven `pom.xml`

Create:

```bash
nano pom.xml
```

Paste:

```xml
<?xml version="1.0" encoding="UTF-8"?>

<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="
             http://maven.apache.org/POM/4.0.0
             https://maven.apache.org/xsd/maven-4.0.0.xsd">

    <modelVersion>4.0.0</modelVersion>

    <groupId>com.hady</groupId>
    <artifactId>kafka-java-maven</artifactId>
    <version>1.0.0</version>

    <properties>
        <maven.compiler.release>21</maven.compiler.release>
        <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>

        <kafka.version>4.3.1</kafka.version>
        <slf4j.version>1.7.36</slf4j.version>
    </properties>

    <dependencies>

        <!-- Kafka Producer, Consumer and Admin APIs -->
        <dependency>
            <groupId>org.apache.kafka</groupId>
            <artifactId>kafka-clients</artifactId>
            <version>${kafka.version}</version>
        </dependency>

        <!-- Logging API -->
        <dependency>
            <groupId>org.slf4j</groupId>
            <artifactId>slf4j-api</artifactId>
            <version>${slf4j.version}</version>
        </dependency>

        <!-- Simple logging implementation for learning -->
        <dependency>
            <groupId>org.slf4j</groupId>
            <artifactId>slf4j-simple</artifactId>
            <version>${slf4j.version}</version>
            <scope>runtime</scope>
        </dependency>

    </dependencies>

    <build>
        <plugins>

            <plugin>
                <groupId>org.apache.maven.plugins</groupId>
                <artifactId>maven-compiler-plugin</artifactId>
                <version>3.15.0</version>
            </plugin>

            <plugin>
                <groupId>org.codehaus.mojo</groupId>
                <artifactId>exec-maven-plugin</artifactId>
                <version>3.6.3</version>

                <configuration>
                    <mainClass>
                        com.hady.kafka.KafkaConnectionCheck
                    </mainClass>
                </configuration>
            </plugin>

        </plugins>
    </build>

</project>
```

The Maven Compiler Plugin uses the JDK compiler to compile the source, while the Exec Maven Plugin lets us run the Java main class directly from Maven. ([Apache Maven](https://maven.apache.org/plugins/maven-compiler-plugin/?utm_source=chatgpt.com 'Introduction – Apache Maven Compiler Plugin'))

Create:

```bash

```

Paste:

```groovy

```

This defines the Gradle project name.

---

### 3. Gradle `build.gradle`

Create:

```bash
nano build.gradle
```

Paste:

```groovy
plugins {
    id 'application'
}

group = 'com.hady'
version = '1.0.0'

repositories {
    mavenCentral()
}

java {
    toolchain {
        languageVersion = JavaLanguageVersion.of(21)
    }
}

dependencies {
    // Kafka Producer, Consumer and Admin APIs
    implementation 'org.apache.kafka:kafka-clients:4.3.1'

    // Logging API
    implementation 'org.slf4j:slf4j-api:1.7.36'

    // Simple logging implementation for learning
    runtimeOnly 'org.slf4j:slf4j-simple:1.7.36'
}

application {
    mainClass = 'com.hady.kafka.KafkaConnectionCheck'
}
```

Gradle toolchains ensure compilation and execution use the configured Java version—in this case Java 21. ([Gradle](https://docs.gradle.org/current/userguide/toolchains.html?utm_source=chatgpt.com 'Toolchains for JVM projects'))

## Override bootstrap servers

Both projects read:

```text
KAFKA_BOOTSTRAP_SERVERS
```

Default:

```text
localhost:29092,localhost:39092,localhost:49092
```

Override it:

```bash
export KAFKA_BOOTSTRAP_SERVERS="localhost:29092"
```

Maven:

```bash
mvn exec:java
```

Gradle:

```bash
./gradlew run
```

Using multiple bootstrap brokers is preferable because the client can make its initial connection even when one bootstrap broker is unavailable. Kafka then discovers and manages connections to the cluster’s brokers. ([Apache Kafka](https://kafka.apache.org/43/configuration/producer-configs/?utm_source=chatgpt.com 'Producer Configs | Apache Kafka'))

## Maven versus Gradle

| Concept         | Maven                    | Gradle              |
| --------------- | ------------------------ | ------------------- |
| Main build file | `pom.xml`                | `build.gradle`      |
| Configuration   | XML                      | Groovy DSL          |
| Compile         | `mvn compile`            | `./gradlew classes` |
| Run             | `mvn exec:java`          | `./gradlew run`     |
| Build output    | `target/`                | `build/`            |
| Dependency      | `<dependency>`           | `implementation`    |
| Java version    | `maven.compiler.release` | Java toolchain      |

### Same Kafka dependency

Maven:

```xml
<dependency>
    <groupId>org.apache.kafka</groupId>
    <artifactId>kafka-clients</artifactId>
    <version>4.3.1</version>
</dependency>
```

Gradle:

```groovy
implementation 'org.apache.kafka:kafka-clients:4.3.1'
```

Both download the same JAR from Maven Central.
