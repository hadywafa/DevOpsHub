
# Complete Kafka Avro Java Lab — Two Separate Projects

I prepared both standalone Maven projects:

[Download producer and consumer projects](sandbox:/mnt/data/kafka-avro-separate-projects.zip)

```text
kafka-avro-separate-projects/
├── kafka-avro-producer/
└── kafka-avro-consumer/
```

Each project compiles and runs independently. Both contain the same Avro contract so they generate compatible `OrderCreated` classes.

This lab uses Java 17, Kafka client `4.3.1`, Confluent serializer `8.3.0`, and Avro `1.12.1`. Confluent Platform 8.3 is based on Kafka 4.3 and supports Java 17. ([Confluent Documentation](https://docs.confluent.io/platform/current/release-notes/index.html?utm_source=chatgpt.com "Release Notes for Confluent Platform 8.3"))

## 1. Prerequisites

Make sure Kafka and Schema Registry are running:

```bash
java -version
mvn -version

curl http://localhost:8080/subjects
```

Expected Schema Registry response initially:

```json
[]
```

Create the topic:

```bash
kafka-topics \
  --bootstrap-server localhost:29092 \
  --create \
  --topic orders-avro \
  --partitions 3 \
  --replication-factor 1
```

When Kafka is running inside Docker, run `kafka-topics` inside the broker container:

```bash
docker exec -it <kafka-container> \
  kafka-topics \
  --bootstrap-server localhost:29092 \
  --create \
  --topic orders-avro \
  --partitions 3 \
  --replication-factor 1
```

## Avro schema

`src/main/avro/OrderCreated.avsc`

```json
{
  "type": "record",
  "name": "OrderCreated",
  "namespace": "com.example.events",
  "fields": [
    { "name": "orderId", "type": "string" },
    { "name": "amount", "type": "double" },
    { "name": "currency", "type": "string", "default": "AED" }
  ]
}
```

During `mvn compile`, `avro-maven-plugin` generates:

```text
target/generated-sources/avro/
└── com/example/events/OrderCreated.java
```

This generated class is Avro’s `SpecificRecord`, similar to generating a strongly typed C# class from a contract. ([Apache Avro](https://avro.apache.org/docs/1.12.0/getting-started-java/?utm_source=chatgpt.com "Getting Started (Java) - Apache Avro"))

## Producer code

`src/main/java/com/example/producer/OrderProducer.java`

```java
package com.example.producer;

import com.example.events.OrderCreated;
import io.confluent.kafka.serializers.KafkaAvroSerializer;
import org.apache.kafka.clients.producer.KafkaProducer;
import org.apache.kafka.clients.producer.ProducerConfig;
import org.apache.kafka.clients.producer.ProducerRecord;
import org.apache.kafka.clients.producer.RecordMetadata;
import org.apache.kafka.common.serialization.StringSerializer;

import java.util.List;
import java.util.Properties;

public final class OrderProducer {

    private static final String TOPIC =
            env("KAFKA_TOPIC", "orders-avro");

    private OrderProducer() {
    }

    public static void main(String[] args) throws Exception {
        Properties config = new Properties();

        config.put(
                ProducerConfig.BOOTSTRAP_SERVERS_CONFIG,
                env("KAFKA_BOOTSTRAP_SERVERS", "localhost:9092")
        );

        config.put(
                ProducerConfig.KEY_SERIALIZER_CLASS_CONFIG,
                StringSerializer.class.getName()
        );

        config.put(
                ProducerConfig.VALUE_SERIALIZER_CLASS_CONFIG,
                KafkaAvroSerializer.class.getName()
        );

        config.put(
                "schema.registry.url",
                env("SCHEMA_REGISTRY_URL", "http://localhost:8081")
        );

        config.put("auto.register.schemas", true);
        config.put(ProducerConfig.ACKS_CONFIG, "all");

        List<OrderCreated> orders = List.of(
                newOrder("ORD-1001", 250.00, "AED"),
                newOrder("ORD-1002", 410.50, "USD"),
                newOrder("ORD-1003", 99.99, "AED")
        );

        try (KafkaProducer<String, OrderCreated> producer =
                     new KafkaProducer<>(config)) {

            for (OrderCreated order : orders) {
                String key = order.getOrderId().toString();

                ProducerRecord<String, OrderCreated> record =
                        new ProducerRecord<>(TOPIC, key, order);

                RecordMetadata metadata =
                        producer.send(record).get();

                System.out.printf(
                        "Produced key=%s amount=%.2f %s -> partition=%d offset=%d%n",
                        key,
                        order.getAmount(),
                        order.getCurrency(),
                        metadata.partition(),
                        metadata.offset()
                );
            }
        }
    }

    private static OrderCreated newOrder(
            String orderId,
            double amount,
            String currency
    ) {
        return OrderCreated.newBuilder()
                .setOrderId(orderId)
                .setAmount(amount)
                .setCurrency(currency)
                .build();
    }

    private static String env(String name, String defaultValue) {
        String value = System.getenv(name);
        return value == null || value.isBlank()
                ? defaultValue
                : value;
    }
}
```

When `producer.send()` executes:

```text
OrderCreated object
        ↓
KafkaAvroSerializer
        ↓
Register/find OrderCreated schema
        ↓
Schema Registry returns schema ID
        ↓
Magic byte + schema ID + Avro binary
        ↓
Kafka
```

The serializer stores only the schema ID and Avro binary in the Kafka value, not the complete schema. ([Confluent Documentation](https://docs.confluent.io/platform/current/schema-registry/fundamentals/serdes-develop/serdes-avro.html?utm_source=chatgpt.com "Apache Avro for Kafka | Serialization, Schema ..."))

## Consumer code

`src/main/java/com/example/consumer/OrderConsumer.java`

```java
package com.example.consumer;

import com.example.events.OrderCreated;
import io.confluent.kafka.serializers.KafkaAvroDeserializer;
import org.apache.kafka.clients.consumer.ConsumerConfig;
import org.apache.kafka.clients.consumer.ConsumerRecord;
import org.apache.kafka.clients.consumer.ConsumerRecords;
import org.apache.kafka.clients.consumer.KafkaConsumer;
import org.apache.kafka.common.errors.WakeupException;
import org.apache.kafka.common.serialization.StringDeserializer;

import java.time.Duration;
import java.util.List;
import java.util.Properties;
import java.util.concurrent.atomic.AtomicBoolean;

public final class OrderConsumer {

    private static final String TOPIC =
            env("KAFKA_TOPIC", "orders-avro");

    private OrderConsumer() {
    }

    public static void main(String[] args) {
        Properties config = new Properties();

        config.put(
                ConsumerConfig.BOOTSTRAP_SERVERS_CONFIG,
                env("KAFKA_BOOTSTRAP_SERVERS", "localhost:9092")
        );

        config.put(
                ConsumerConfig.GROUP_ID_CONFIG,
                env(
                        "KAFKA_CONSUMER_GROUP",
                        "orders-avro-java-consumer"
                )
        );

        config.put(
                ConsumerConfig.KEY_DESERIALIZER_CLASS_CONFIG,
                StringDeserializer.class.getName()
        );

        config.put(
                ConsumerConfig.VALUE_DESERIALIZER_CLASS_CONFIG,
                KafkaAvroDeserializer.class.getName()
        );

        config.put(
                "schema.registry.url",
                env("SCHEMA_REGISTRY_URL", "http://localhost:8081")
        );

        config.put(ConsumerConfig.AUTO_OFFSET_RESET_CONFIG, "earliest");
        config.put(ConsumerConfig.ENABLE_AUTO_COMMIT_CONFIG, false);

        // Return OrderCreated instead of GenericRecord
        config.put("specific.avro.reader", true);

        AtomicBoolean running = new AtomicBoolean(true);

        try (KafkaConsumer<String, OrderCreated> consumer =
                     new KafkaConsumer<>(config)) {

            Runtime.getRuntime().addShutdownHook(
                    new Thread(() -> {
                        running.set(false);
                        consumer.wakeup();
                    })
            );

            consumer.subscribe(List.of(TOPIC));

            System.out.printf(
                    "Listening on topic '%s'. Press Ctrl+C to stop.%n",
                    TOPIC
            );

            try {
                while (running.get()) {
                    ConsumerRecords<String, OrderCreated> records =
                            consumer.poll(Duration.ofSeconds(1));

                    for (ConsumerRecord<String, OrderCreated> record
                            : records) {

                        OrderCreated order = record.value();

                        System.out.printf(
                                "Consumed key=%s orderId=%s amount=%.2f %s "
                                        + "partition=%d offset=%d%n",
                                record.key(),
                                order.getOrderId(),
                                order.getAmount(),
                                order.getCurrency(),
                                record.partition(),
                                record.offset()
                        );
                    }

                    if (!records.isEmpty()) {
                        consumer.commitSync();
                    }
                }
            } catch (WakeupException e) {
                if (running.get()) {
                    throw e;
                }
            }
        }
    }

    private static String env(String name, String defaultValue) {
        String value = System.getenv(name);
        return value == null || value.isBlank()
                ? defaultValue
                : value;
    }
}
```

During `poll()`:

```text
Kafka returns bytes
        ↓
KafkaAvroDeserializer
        ↓
Read schema ID
        ↓
Retrieve/cache schema from Schema Registry
        ↓
Decode Avro payload
        ↓
specific.avro.reader=true
        ↓
Create OrderCreated object
```

The consumer knows the value is Avro because `KafkaAvroDeserializer` is configured. The embedded schema ID tells it which Avro writer schema to retrieve. ([Confluent Documentation](https://docs.confluent.io/platform/current/schema-registry/fundamentals/serdes-develop/serdes-avro.html?utm_source=chatgpt.com "Apache Avro for Kafka | Serialization, Schema ..."))

# 4. Maven configuration

Both projects use nearly the same `pom.xml`.

The producer uses:

```xml
<artifactId>kafka-avro-producer</artifactId>
```

and:

```xml
<mainClass>com.example.producer.OrderProducer</mainClass>
```

The consumer uses:

```xml
<artifactId>kafka-avro-consumer</artifactId>
```

and:

```xml
<mainClass>com.example.consumer.OrderConsumer</mainClass>
```

The complete POM files are included in the ZIP. Their essential dependencies are:

```xml
<dependencies>
    <dependency>
        <groupId>org.apache.kafka</groupId>
        <artifactId>kafka-clients</artifactId>
        <version>4.3.1</version>
    </dependency>

    <dependency>
        <groupId>org.apache.avro</groupId>
        <artifactId>avro</artifactId>
        <version>1.12.1</version>
    </dependency>

    <dependency>
        <groupId>io.confluent</groupId>
        <artifactId>kafka-avro-serializer</artifactId>
        <version>8.3.0</version>
    </dependency>
</dependencies>
```

Confluent dependencies require this repository:

```xml
<repositories>
    <repository>
        <id>confluent</id>
        <url>https://packages.confluent.io/maven/</url>
    </repository>
</repositories>
```

## Common errors

**`Unknown magic byte`**

The topic contains plain JSON/string records, but the consumer uses `KafkaAvroDeserializer`.

**`GenericData$Record cannot be cast to OrderCreated`**

Confirm:

```java
config.put("specific.avro.reader", true);
```

**Schema Registry connection refused**

Check:

```bash
curl http://localhost:8080/subjects
```

**Applications run inside Docker**

Replace:

```text
localhost:29092
http://localhost:808
```

with the Docker service names visible from the application container.

I validated the project structure and both POM files syntactically. I could not execute Maven dependency resolution in this environment because Maven was unavailable and outbound DNS access was blocked.
