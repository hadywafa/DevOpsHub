# Avro Tools  

`avro-tools` is an executable Java JAR containing command-line utilities for working with Avro schemas and **Avro Object Container Files** (`.avro`). ([Apache Avro](https://avro.apache.org/docs/1.12.0/api/java/org/apache/avro/tool/package-summary.html?utm_source=chatgpt.com "org.apache.avro.tool (Apache Avro Java 1.12.0 API)"))

Run it like:

```bash
java -jar avro-tools-1.12.0.jar <command>
```

To see all commands:

```bash
java -jar avro-tools-1.12.0.jar
```

## Most useful commands

### 1. Generate Java classes from a schema

```bash
java -jar avro-tools-1.12.0.jar \
  compile schema \
  src/main/avro/OrderCreated.avsc \
  target/generated-sources/avro
```

This generates your `SpecificRecord` Java class:

```text
OrderCreated.avsc
        ↓
OrderCreated.java
```

In Maven projects, the `avro-maven-plugin` normally automates this during `mvn compile`, so you rarely run this command manually. ([Apache Avro](https://avro.apache.org/docs/1.12.0/getting-started-java/?utm_source=chatgpt.com "Getting Started (Java) | Apache Avro"))

---

### 2. Convert JSON records into an Avro file

Given `orders.json`:

```json
{"orderId":"ORD-1001","amount":250.0}
{"orderId":"ORD-1002","amount":400.0}
```

Run:

```bash
java -jar avro-tools-1.12.0.jar \
  fromjson \
  --schema-file OrderCreated.avsc \
  orders.json > orders.avro
```

Result:

```text
JSON records + schema → orders.avro
```

---

### 3. Read an Avro file as JSON

```bash
java -jar avro-tools-1.12.0.jar \
  tojson \
  --pretty \
  orders.avro
```

Useful when inspecting binary Avro files:

```text
orders.avro → readable JSON
```

---

### 4. Extract the schema from an Avro file

```bash
java -jar avro-tools-1.12.0.jar \
  getschema orders.avro
```

Avro Object Container Files store their schema inside the file, so they can later be read without supplying a separate `.avsc` file. ([Apache Avro](https://avro.apache.org/docs/?utm_source=chatgpt.com "Documentation | Apache Avro"))

---

### 5. Inspect file metadata

```bash
java -jar avro-tools-1.12.0.jar \
  getmeta orders.avro
```

This displays information such as:

```text
Schema
Compression codec
Custom metadata
```

---

## Important Kafka distinction

A `.avro` file normally contains:

```text
File header + embedded schema + metadata + Avro records
```

A Kafka message using Confluent Avro normally contains:

```text
Magic byte + Schema ID + raw Avro payload
```

Therefore, you cannot normally copy a Kafka message and pass it directly to:

```bash
avro-tools tojson
```

You first need the schema from Schema Registry and must remove or understand the Confluent framing.

## Practical use

Use `avro-tools` mainly for:

```text
Testing schemas
Generating Java classes
Creating sample Avro files
Converting Avro files to JSON
Inspecting schema and metadata
```

For normal Maven development, class generation is better handled automatically by `avro-maven-plugin`.
