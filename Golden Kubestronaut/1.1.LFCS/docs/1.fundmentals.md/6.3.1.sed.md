# 🧩 **What is `sed`?**

`sed` = **Stream EDitor**.

It reads input **line by line**, applies transformations, and outputs the result.
Perfect for:

- Editing files automatically
- Scripting
- CI/CD pipelines
- Config transformations
- Log cleanup
- Mass replacements

Syntax:

```bash
sed 'COMMAND' file
```

or multiple:

```bash
sed -e 'command1' -e 'command2' file
```

---

## 📌 **Important Notes Before We Begin**

- `sed` **does not change the file** unless you use:

  ```bash
  sed -i '...' file   # in-place edit
  ```

- Most commands use **regex**
- **Addresses** (line numbers or patterns) can target specific lines

---

## 🟥 1. FIND & REPLACE (`s///`)

Basic syntax:

```bash
sed 's/pattern/replacement/' file
```

---

### 🔹 Replace `first` occurrence **per line**

```bash
sed 's/error/ERROR/' file.txt
```

---

### 🔹 Replace `ALL` occurrences **per line** (`g` flag)

```bash
sed 's/error/ERROR/g' file.txt
```

---

### 🔹 Case-insensitive replace

```bash
sed 's/error/ERROR/gi' file.txt
```

---

### 🔹 In-place replacement (modify file)

```bash
sed -i 's/localhost/127.0.0.1/' config.txt
```

---

### 🔹 Using capture groups (regex)

#### Replace numbers with [NUMBER]

```bash
sed 's/[0-9]\+/[NUMBER]/g' file.txt
```

---

#### Swap two words

```bash
sed 's/\(first\) \(second\)/\2 \1/' file.txt
```

---

## 🟧 2. DELETE LINES (`d`)

Syntax:

```bash
sed 'PATTERN d' file
```

---

### 🔹 Delete lines containing a word

```bash
sed '/DEBUG/d' app.log
```

---

### 🔹 Delete empty lines

```bash
sed '/^$/d' file.txt
```

---

### 🔹 Delete lines by number

Delete line **3**:

```bash
sed '3d' file.txt
```

Delete lines 3 to 7:

```bash
sed '3,7d' file.txt
```

Delete from line 5 to end:

```bash
sed '5,$d' file.txt
```

---

## 🟨 3. INSERT & APPEND (`i`, `a`)

- **Insert (i)** → before the matched line
- **Append (a)** → after the matched line

---

### 🔹 Insert before line number

```bash
sed '3i This is inserted BEFORE line 3' file.txt
```

---

### 🔹 Append after line number

```bash
sed '3a This is inserted AFTER line 3' file.txt
```

---

### 🔹 Insert before lines matching a pattern

```bash
sed '/ERROR/i ----- ERROR FOUND BELOW -----' log.txt
```

---

### 🔹 Append after pattern

```bash
sed '/ERROR/a ----- END OF ERROR -----' log.txt
```

---

## 🟩 4. CHANGE CONTENT OF A LINE (`c`)

Change replaces **the entire line**.

---

### 🔹 Replace entire line containing "DEBUG"

```bash
sed '/DEBUG/c This line was replaced' file.txt
```

---

### 🔹 Replace a specific line number

```bash
sed '5c This is the NEW line 5' file.txt
```

---

## 🟦 5. PRINTING (`p`)

By default, `sed` prints all lines.
`p` prints specific lines.

---

### 🔹 Print only matched lines

```bash
sed -n '/ERROR/p' file.txt
```

`-n` → suppress automatic printing

---

### 🔹 Print specific line number

```bash
sed -n '5p' file.txt
```

---

### 🔹 Print a range

```bash
sed -n '10,20p' file.txt
```

---

## 🟪 6. MULTI-LINE PROCESSING

`sed` is line-based by default, but can use the **hold space** to combine lines.

---

### 🔹 Replace text across two lines

Example file:

```ini
username:
admin
```

Replace that with:

```ini
username: admin
```

```bash
sed ':a;N;$!ba;s/\nadmin/: admin/' file.txt
```

Explanation:

- `N` → append next line
- `ba` → loop
- Whole file becomes one line → then processed

---

### 🔹 Remove line breaks (join lines)

```bash
sed ':a;N;$!ba;s/\n/ /g' file.txt
```

---

### 🔹 Append next line to current line

```bash
sed 'N;s/\n/ /' file.txt
```

## 🟫 SED REGEX CHEATSHEET

### Basic

| Regex     | Meaning             |
| --------- | ------------------- |
| `.`       | any char            |
| `*`       | 0 or more           |
| `+`       | 1 or more           |
| `?`       | maybe 1             |
| `[a-z]`   | range               |
| `^word`   | starts with word    |
| `word$`   | ends with word      |
| `\(`…`\)` | capture group       |
| `\|`      | OR (extended regex) |

Enable extended regex:

```bash
sed -E 's/a|b/c/' file
```

## 🔥 REAL DEVOPS USE CASES

### ✔ 1. Replace env variable in configuration

```bash
sed -i 's/DB_HOST=.*/DB_HOST=prod-db/' .env
```

Before:

```ini
DB_HOST=localhost
```

After:

```ini
DB_HOST=prod-db
```

---

### ✔ 2. Comment out a line in config

```bash
sed -i '/^Listen 80/s/^/#/' httpd.conf
```

---

### ✔ 3. Remove all comments

```bash
sed '/^#/d' config.conf
```

---

### ✔ 4. Extract only IP addresses from log

```bash
sed -n 's/.*IP: \([0-9\.]*\).*/\1/p' app.log
```

---

### ✔ 5. Change JSON values (yes, sed can do it)

```bash
sed -i 's/"replicas": [0-9]\+/"replicas": 5/' deployment.json
```

---

### ✔ 6. Remove ANSI color codes from logs

```bash
sed 's/\x1b\[[0-9;]*m//g' logfile
```

## `sed` — remember it forever

Think of `sed` as:

> **S**tream **ED**itor = find text and change it while it flows past.

### Core pattern

```bash
sed 's/OLD/NEW/' file
```

Remember:

```text
s = substitute
OLD = what to find
NEW = replacement
```

Example:

```bash
sed 's/dev/prod/' config.txt
```

Changes the **first** `dev` on each line.

### The 4 things worth memorizing

```bash
# Replace first match per line
sed 's/foo/bar/' file

# Replace ALL matches per line
sed 's/foo/bar/g' file

# Edit the actual file
sed -i 's/foo/bar/g' file

# Delete matching lines
sed '/error/d' file
```

Mnemonic:

```text
s = substitute
g = global
-i = in-place
d = delete
```

### Useful extras

Print only matching lines:

```bash
sed -n '/error/p' file
```

Print a specific line:

```bash
sed -n '5p' file
```

Delete lines 5–10:

```bash
sed '5,10d' file
```

Replace only on line 5:

```bash
sed '5s/foo/bar/' file
```

### LFCS-style example

Change SSH port:

```bash
sed -i 's/^#Port 22/Port 2222/' /etc/ssh/sshd_config
```

Then verify:

```bash
grep '^Port' /etc/ssh/sshd_config
```

The mental model is simply:

```text
sed 'COMMAND' file

Find → Change/Delete/Print → Output
```

If you remember only one command, remember:

```bash
sed -i 's/old/new/g' file
```

## 🧠 SUMMARY TABLE

| Action               | sed command          |
| -------------------- | -------------------- |
| Replace text         | `s/old/new/`         |
| Replace globally     | `s/old/new/g`        |
| In-place edit        | `sed -i`             |
| Delete lines         | `/pattern/d` or `3d` |
| Insert               | `/pat/i text`        |
| Append               | `/pat/a text`        |
| Change entire line   | `/pat/c text`        |
| Print only matches   | `sed -n '/pat/p'`    |
| Multi-line join      | `N; s/\n/ /`         |
| Replace across lines | `:a;N;$!ba; s/.../`  |
