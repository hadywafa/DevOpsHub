# 📂 The Most Important Linux File Commands (Your Style)

These are the _core navigation and file manipulation commands_ every engineer must know.

- `pwd` → show where you are
- `cd` → move around
- `touch` → create/update files
- `cp` → copy
- `mv` → move/rename
- `rm` → delete

Let’s go one by one 👇

---

## 📍 1. `pwd` — Print Working Directory

Shows your **current location** in the filesystem.

### ▶️ Command

```bash
pwd
```

### 📤 Expected Output

```text
/home/user/projects
```

### 💡 When to use?

- When you're lost
- Before running commands like `rm`, `cp`, `mv`
- Inside scripts to verify paths

---

## 📁 2. `cd` — Change Directory

Moves you from one directory to another.

---

### 🟦 Basic Usage

#### ▶️ Go to another directory

```bash
cd /home/user/projects
```

#### ▶️ Go up one level

```bash
cd ..
```

#### ▶️ Go to your home directory

```bash
cd ~
```

or simply:

```bash
cd
```

---

### 🟦 Examples + Expected Output

#### Example 1: Move into "Documents"

```bash
cd ~/Documents
pwd
```

Output:

```text
/home/user/Documents
```

#### Example 2: Go back to previous directory

```bash
cd -
```

Output:

```text
/home/user/projects
```

---

## 📄 3. `touch` — Create Empty Files OR Update Modified Time

### 🟩 Basic Usage

#### ▶️ Create a new empty file

```bash
touch notes.txt
```

#### ▶️ Update last-modified timestamp

```bash
touch notes.txt
```

_(File already exists → timestamp updates)._

---

### 🟩 Examples + Expected Output

#### Example 1: Create multiple files

```bash
touch file1.txt file2.txt file3.txt
```

Output: _(No output = success)_

#### Example 2: Check timestamp update

```bash
ls -l notes.txt
```

Output:

```text
-rw-rw-r-- 1 user user 0 Jan 20 10:45 notes.txt
```

---

## 📁 4. `mkdir` — Create Directories

Creates one or more directories.

---

### 🟦 Basic Syntax

```bash
mkdir <directory-name>
```

---

### 🟦 Useful Options

| Flag | Meaning                             |
| ---- | ----------------------------------- |
| `-p` | Create parent directories if needed |
| `-v` | Verbose: show created dirs          |

---

### 🟦 Examples + Expected Outputs

#### Example 1 — Create one directory

```bash
mkdir projects
```

_(No output = success)._

---

#### Example 2 — Create nested directories

```bash
mkdir -p project/src/utils
```

Output (with `-v`):

```text
mkdir: created directory 'project'
mkdir: created directory 'project/src'
mkdir: created directory 'project/src/utils'
```

---

## 🗣️ 5. `echo` — Print Text to Terminal or File

`echo` is used to:

✔ Print text
✔ Write text into files
✔ Append text to files

---

### 🟩 Basic Syntax

```bash
echo <text>
```

---

### 🟩 Examples

#### Example 1 — Print text

```bash
echo "Hello Linux"
```

Output:

```text
Hello Linux
```

---

#### Example 2 — Write to a file (overwrite)

```bash
echo "Welcome to Linux" > intro.txt
```

---

#### Example 3 — Append text to a file

```bash
echo "New line" >> intro.txt
```

---

#### Example 4 — Echo environment variable

```bash
echo $HOME
```

Output example:

```text
/home/user
```

---

## 📑 6. `cp` — Copy Files and Directories

### 🟧 Basic Syntax

```bash
cp source destination
```

---

### 🟧 Common Options

| Flag | Meaning                            |
| ---- | ---------------------------------- |
| `-r` | copy directories recursively       |
| `-v` | verbose: show what is being copied |
| `-i` | interactive: ask before overwrite  |

---

### 🟧 Examples

#### Example 1: Copy a file

```bash
cp file1.txt backup.txt
```

Output: _(none)_

#### Example 2: Copy a directory (recursive)

```bash
cp -r project/ project_backup/
```

Output:

```txt
'project/' -> 'project_backup/'
'project/app.py' -> 'project_backup/app.py'
...


# if project_backup is already there
# the it will copy whole folder inside it not just the folder content

```
(with `-v`)

---

## 🔀 7. `mv` — Move or Rename Files/Directories

### 🟨 Basic Syntax

```bash
mv source destination
```

---

### 🟨 Uses

- ✔ Move files
- ✔ Rename files
- ✔ Move directories
- ✔ Overwrite targets (unless `-i` is used)

---

### 🟨 Examples

#### Example 1: Rename a file

```bash
mv oldname.txt newname.txt
```

Output: _(none)_

#### Example 2: Move file into a directory

```bash
mv report.txt /home/user/Documents/
```

#### Example 3: Move multiple files

```bash
mv *.log logs/
```

---

### ❌ 6. `rm` — Remove Files and Directories (Dangerous!)

### 🟥 Basic Syntax

```bash
rm filename
```

---

### 🟥 Important Flags

| Flag | Meaning                           |
| ---- | --------------------------------- |
| `-r` | recursive (delete directories)    |
| `-f` | force delete (no confirmation)    |
| `-i` | interactive (ask before deleting) |

---

### 🟥 Examples

#### Example 1: Delete a single file

```bash
rm notes.txt
```

#### Example 2: Delete a directory

```bash
rm -r old_project/
```

#### Example 3: Force delete without prompt

```bash
rm -rf temp/
```

⚠️ **Be extremely careful.**  
`rm -rf /` → deletes everything (on systems that don't protect root).
Never run destructive commands unless you verify with:

```bash
pwd
ls
```
