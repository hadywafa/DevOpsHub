# 🔍 **What is `grep`?**

`grep` = **Global Regular Expression Print**
It searches text in files and prints matching lines.

Works with:

- log files
- code
- system configs
- JSON/YAML
- pipeline outputs
- big directories
- stdin (piped data)

`grep` + `tail`, `awk`, `sed`, and `find` = DevOps power combo.

---

## 🧩 **Basic Syntax**

```bash
grep "pattern" file
```

Or recursive:

```bash
grep -r "pattern" directory/
```

Or from a pipe:

```bash
cat file | grep ERROR
```

---

## 🟥 1. BASIC SEARCHING

### 🔹 Search for exact text

```bash
grep "hello" file.txt
```

---

### 🔹 Case-insensitive search

```bash
grep -i "hello" file.txt
```

Matches:
`hello`, `Hello`, `HELLO`, `HeLlO`

---

### 🔹 Search multiple files

```bash
grep "ERROR" *.log
```

---

### 🔹 `Show filenames only`

```bash
grep -l "ERROR" *.log
```

Output:

```ini
app.log
server.log
```

---

## 🟧 2. REGEX SEARCHING

### 🔹 Extended regex (`-E`)

```bash
grep -E "ERROR|WARNING" file.log
```

---

### 🔹 Match digits

```bash
grep -E "[0-9]+" file.txt
```

---

### 🔹 Match IP addresses

```bash
grep -E "([0-9]{1,3}\.){3}[0-9]{1,3}" access.log
```

---

### 🔹 Match lines starting with pattern

```bash
grep "^INFO" app.log
```

---

### 🔹 Match lines ending with pattern

```bash
grep "failed$" app.log
```

---

## 🟨 3. INVERSE MATCHING (NOT)

### 🔹 Exclude lines with pattern

```bash
grep -v "INFO" app.log
```

---

### 🔹 `Exclude empty lines`

```bash
grep -v "^$" file.txt
```

---

## 🟩 4. MATCH WHOLE WORDS

### 🔹 Match ONLY the full word

```bash
grep -w "error" file.txt
```

Matches:
`error`
Does NOT match:
`errors`, `terror`, `error123`

---

## 🟦 5. SHOW LINE NUMBERS

```bash
grep -n "ERROR" app.log
```

Output:

```ini
34: ERROR connection refused
120: ERROR timeout
```

---

## 🟪 6. HIGHLIGHT MATCHES

Most systems support:

```bash
grep --color "pattern" file
```

---

## 🟫 7. RECURSIVE SEARCH

### 🔹 Search through directory recursively

```bash
grep -r "TODO" .
```

---

### 🔹 Only show filenames

```bash
grep -rl "TODO" .
```

---

### 🔹 Ignore binary files

```bash
grep -rI "TODO" .
```

---

## 🟥 8. CONTEXT LINES (super important for logs)

Useful when checking logs around errors.

---

### 🔹 Show 3 lines BEFORE match

```bash
grep -B 3 "ERROR" app.log
```

---

### 🔹 Show 3 lines AFTER match

```bash
grep -A 3 "ERROR" app.log
```

---

### 🔹 Show 3 lines before & after

```bash
grep -C 3 "ERROR" app.log
```

Output:

```ini
INFO User logged in
INFO Request sent
ERROR Connection failed
INFO Retrying...
INFO Timeout
```

---

## 🟧 9. COUNT MATCHES

---

### 🔹 Count lines that match

```bash
grep -c "ERROR" app.log
```

---

### 🔹 Count how many files contain pattern

```bash
grep -rl "ERROR" . | wc -l
```

---

## 🟨 10. MATCH MULTIPLE PATTERNS

### 🔹 Using `-e`

```bash
grep -e "ERROR" -e "CRITICAL" app.log
```

---

### 🔹 Using regex

```bash
grep -E "ERROR|CRITICAL" app.log
```

---

## 🟦 11. MATCH ENTIRE FILES (binary, unreadable)

### 🔹 Treat binary as text

```bash
grep -a "password" binaryfile
```

---

### 🔹 Show if file contains match (no lines)

```bash
grep -q "secret" file.txt
```

Return codes:

| Meaning     | Code |
| ----------- | ---- |
| Match found | 0    |
| No match    | 1    |
| Error       | 2    |

Perfect for scripts:

```bash
if grep -q "ERROR" app.log; then
    echo "Error detected!"
fi
```

## 🟩 12. GREP WITH PIPELINES

---

### 🔹 Filter output of other commands

```bash
ps aux | grep nginx
```

---

### 🔹 Get only network lines

```bash
ip a | grep inet
```

---

### 🔹 Find failed login attempts

```bash
journalctl -u ssh | grep "Failed"
```

---

### 🔹 Filter Kubernetes logs

```bash
kubectl logs app | grep "ERROR"
```

---

## 🟪 13. NEGATIVE GREP (double invert)

Remove all lines **except errors**:

```bash
grep -E "ERROR|CRITICAL" app.log | grep -v "DEBUG"
```

---

## 🟫 14. ADVANCED REGEX (for pros)

Enable extended regex:

```bash
grep -E "pattern"
```

Examples:

---

### Match email addresses

```bash
grep -E "[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}" file.txt
```

---

### Match dates YYYY-MM-DD

```bash
grep -E "[0-9]{4}-[0-9]{2}-[0-9]{2}" file.txt
```

---

### Match function definitions (C-like)

```bash
grep -E "^[a-zA-Z_][a-zA-Z0-9_]*\(" code.c
```

## 🧠 15. REAL DEVOPS EXAMPLES

### ✔ K8s: find pods in CrashLoopBackOff

```bash
kubectl get pods | grep CrashLoopBackOff
```

---

### ✔ Logs: filter only errors (ignore INFO)

```bash
grep -v "INFO" /var/log/app.log | grep "ERROR"
```

---

### ✔ CI/CD: check version string

```bash
grep -E "version: [0-9]+\.[0-9]+" build.yaml
```

---

### ✔ Search environment variables

```bash
env | grep "AWS"
```

---

### ✔ Search Java stack trace sections

```bash
grep -A 10 -B 4 "Exception" app.log
```

---

### ✔ Get only failed requests from NGINX logs

```bash
grep " 500 " access.log
```

---

### ✔ Extract failed authentication attempts

```bash
grep "Failed password" /var/log/auth.log
```
